# 豆包同步

把豆包对话同步为本地 Obsidian Markdown。第一版仅支持桌面端，提供内置登录窗口、手动与定时同步、按会话 ID 更新笔记，以及同步结果提示。项目命名、设置页和 frontmatter 沿用「得到大脑同步」的风格。

## 本地安装

1. 在项目目录运行 `npm install` 和 `npm run build`。
2. 在目标 vault 下创建 `.obsidian/plugins/doubao-sync/`。
3. **只复制** `main.js`、`manifest.json`、`styles.css` 到这个目录。
4. 在 Obsidian「设置 → 第三方插件」启用「Doubao Sync」，重载应用。
5. 打开插件设置，点击「登录豆包」，在弹出的豆包窗口完成正常登录，关闭窗口后点击「同步」。

登录态保存在本机 Electron 独立会话中，插件设置和日志不保存 Cookie 明文。

## 当前范围

- 每次从豆包网页接口请求最近至多 200 个会话，并分页读取每个会话的消息。达到列表上限时会提示可能尚未覆盖更早历史。
- 一个会话生成一篇 Markdown。再次同步按 `uid` 找回被移动或重命名的笔记，只更新插件管理的正文区，保留手写批注和非插件字段。
- 同步失败的会话不推进检查点，远端删除不触发本地删除。
- 图片和文件目前只保留可用的原始链接，不下载到 vault。
- 豆包网页接口是非公开接口；如响应结构变化，会报错并停止相关写入。

此版本尚未用你的登录账号完成真实接口验收。安装后第一次同步的结果，是确认网页接口是否仍适用的关键一步。

后续步骤见[演进计划](docs/EVOLUTION.md)。
