# 豆包同步

把豆包对话同步为本地 Obsidian Markdown。桌面端提供内置登录、手动/自动同步、实时页数进度、取消和最近30天逐会话日志。设置组件、反馈方式和 frontmatter 沿用「得到大脑同步」的成熟设计，见[复用边界](docs/REUSE.md)。

## 本地安装

1. 在项目目录运行 `npm install` 和 `npm run build`。
2. 在目标 vault 下创建 `.obsidian/plugins/doubao-sync/`。
3. **只复制** `main.js`、`manifest.json`、`styles.css` 到这个目录。
4. 在 Obsidian「设置 → 第三方插件」启用「Doubao Sync」。更新已启用的插件时，仅关闭后重新启用此插件即可加载新版本，无需重载整个应用。
5. 打开插件设置，展开「更改凭证 → 凭证设置」，点击「网页登录」，在弹出的豆包窗口完成正常登录；服务端验证成功后窗口自动关闭，状态显示「认证成功」。
6. 在「同步 → 目标文件夹」选择保存位置，再点击「手动同步 → 同步对话」。新装默认不开启自动同步，随时可手动使用；如需定时执行，开启「启用自动同步」。

登录态保存在本机 Electron 独立会话中，插件设置和日志不保存 Cookie 明文。

## 使用与反馈

- 「自动同步」默认收起详情，摘要显示间隔、启动策略和仅下载模式。展开后可填写 5–1440 分钟的整数，非法输入不会保存。新装默认周期 30 分钟，启动时同步勾选但仅在自动同步开启时生效；升级不会更改已有配置。
- 当前状态与上次同步位于顶部；任务开始后，在同一位置查看会话处理进度、当前标题、页数及消息数。获取列表时不伪造百分比，百分比仅表示已完成会话数量的比例。
- 点击「取消同步」可停止当前任务，保留已完成笔记；需要时再次同步继续。关闭登录窗口后可再次点击登录按钮重新打开。
- 「查看日志」按每页 5 条显示最近 30 天记录，最新或失败记录默认展开；新增、更新、跳过和失败分组，失败原因保留。无变化仍显示跳过数量。
- 自动同步无变化时保持安静；有新内容时温和提示。失败、登录失效或列表触顶会提醒，同一未解决问题不在每个周期重复打扰。
- 设置页的「同步对话」、命令「按时间同步豆包对话」和侧栏消息图标都会先打开范围选择。可以选最近 N 天、从指定日期开始或不限时间。原命令 ID 不变，已有快捷键可继续使用。

## 笔记格式

核心属性沿用得到大脑同步的 `uid`、`title`、`created`、`modified`、`source`、`tags`；豆包现有字段为 `conversation_type`、`source_url`、`message_count`、`doubao_sync_schema`、`doubao_source_hash`。保留这些已落盘字段名，不为界面对齐迁移笔记。原始时间有效时才写 `created` / `modified`。

对话正文位于 `<!-- doubao-sync:source-body:start -->` 和 `<!-- doubao-sync:source-body:end -->` 之间；自定义 frontmatter 和边界外批注会保留。

## 当前范围

- 手动同步按豆包返回的游标翻页，按会话更新时间筛选，并读取命中会话的完整消息。若更新时间缺失则使用创建时间，两者都缺失时也纳入。范围写入同步日志。
- 自动同步每轮请求至多 200 个近期会话。实际覆盖范围取决于豆包网页接口返回的可见会话。
- 单个会话最多读取 1000 页；分页重复、游标异常或达到上限时跳过，不保存不完整对话。
- 一个会话生成一篇 Markdown。再次同步按 `uid` 找回被移动或重命名的笔记，只更新插件管理的正文区，保留手写批注和非插件字段。
- 同步失败的会话不推进检查点，远端删除不触发本地删除。
- 即使会话更新时间没变，也会检查最近一页消息的版本；版本变化时重读并更新笔记。旧版升级首次需重新读取现有会话以建立版本记录，之后只重读变化项。
- 同步时可取消；取消或登录失效会保留已完成会话，未完成会话不写入不完整正文。关闭插件会取消请求并关闭隐藏窗口。
- 设置页显示真实连接状态、任务阶段、会话计数和当前消息页数；日志记录手动/自动来源、耗时、逐会话结果和错误，不保存对话正文。
- 图片和文件目前只保留可用的原始链接，不下载到 vault。
- 豆包网页接口是非公开接口；如响应结构变化，会报错并停止相关写入。
