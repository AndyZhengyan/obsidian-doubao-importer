# 姊妹版复用边界

## 后续改动怎么参考得到大脑

先核对参考仓库当前提交和实际安装版本。截图、源码和运行结果不一致时，分别记录，不能把旧截图当成现行规范。每个改动先找原插件中用户会走的对应路径，从入口看到结束，再决定复用什么。

| 对照面 | 要看什么 | 怎么验收 |
| --- | --- | --- |
| 入口与设置 | 设置页、命令、Ribbon 的命名与排列；默认值、折叠、禁用、键盘操作 | 在同一 Obsidian 主题下操作两个插件；检查首次安装和旧配置升级 |
| 状态与文案 | 未登录、验证中、成功、无变化、部分失败、取消、重试；看按钮、状态栏、通知和日志是否一致 | 同一任务从入口走到结果；错误能给出下一步，无变化不打扰 |
| 同步与笔记 | 稳定 ID、已有文件定位、字段归属、正文边界、失败检查点 | 用现有笔记验证重复同步、失败和取消；核对手写内容不被覆盖、远端消失不删除本地 |
| 工程与交付 | 参考同类回归测试、构建产物、PR 和验收记录 | 分开记录代码检查、本地部署、真实运行和发布；不以一个通过代替另一个 |

能直接移植的，连组件、样式、文案和测试场景一起参考；只需替换平台名的，不重写语气。语义不同的保留差异，并写明原因。无需为复用引入不存在的功能，也不为对齐命名而迁移已写入的用户笔记。新改动在 PR 中注明对照来源、保留点、必要差异和实测结果。

「上次同步」沿用得到大脑的相对时间，并保留完整时间供悬停查看；手动测试连接通过服务端验证后显示「连接成功」，启动检查不额外提示。目标文件夹沿用 Obsidian 原生目录建议：输入筛选已有目录，选择后走原有保存流程，也可直接输入新路径。豆包没有手填服务地址项，不增加无用输入框。

第一轮从 `obsidian-getnote-importer` 的提交 `4a5e2cc7c82a8f03b3169e76db1ebbe9a5b09c95`（MIT）移植成熟组件和设计模式。所有代码随豆包插件构建，不要求安装额外插件。

- `src/settings/setting-item.tsx`：名称、说明、控件三段结构，近原样移植。
- `src/settings/toggle.tsx`：Obsidian 原生开关外观、可访问标签、即时状态和禁用处理。
- `src/settings-tab.tsx`：稳定挂载和运行态刷新模式，改为 `SettingsView` / `SettingsActions`，不依赖得到大脑插件实例。
- `src/ui/sync-history-modal.ts`：分页、折叠摘要、逐项结果、异常展开的交互，适配会话结果。
- `src/types.ts` / `src/history.ts`：采用相同的成功、部分完成、失败、取消语义和30天保留规则；逐条检查点仍使用豆包自己的逻辑。

本轮是有来源记录的组件移植，不是两个仓库已经共同依赖一个公共包。得到大脑原项目未修改。后续再把已在两侧证明稳定的展示组件抽为小型共享包，避免长期维护两份副本。

保留平台专属的 `src/api.ts`、消息解析和笔记渲染，不移入得到大脑的双向同步、知识库、额度与鉴权模式。当前仍保持原笔记 uid、frontmatter、source-body 标记与目录。

## 2026-10-16：从“基础控件相似”到完整体验对齐

参考源码现场提交仍为 `4a5e2cc7c82a8f03b3169e76db1ebbe9a5b09c95`。这一轮不再单独设计设置页和日志卡片，而是逐项移植其已打磨的结构与样式。

| 得到大脑来源 | 豆包落地 | 保留与调整 |
| --- | --- | --- |
| `src/settings/index.tsx` | 同路径 | 标题/作者/帮助链接、状态条、凭证折叠、引导、同步/高级区折叠、自动同步主行与摘要、手动下载操作组、日志入口；只移除平台不存在的配置 |
| `styles.css` 设置相关规则 | `src/styles.css` → 构建为 `styles.css` | 复用间距、输入宽度、左右对齐、行结构、折叠箭头、链接式展开、进度条、700px 响应式；所有规则限定豆包范围 |
| `PathSuggest` / `ExternalLink` | `src/settings/path-suggest.ts` / `external-link.tsx` | 使用 Obsidian 原生目录建议；通过 Electron 外部打开真实项目帮助链接 |
| `src/ui/sync-history-modal.tsx` 与日志 CSS | `src/ui/sync-history-modal.ts` / `history.css` | 摘要拆分、状态色、四格元信息、四计数卡、写入结果标签、失败/跳过分组、分页与关闭清理；不虚构笔记类型与日期过滤 |
| `src/ui/notice.ts` | 同路径 | `[豆包]` 前缀、成功/错误图标、时长、样式；错误保留原因并给出下一步；自动无变化静默，重复故障去重 |
| `src/i18n.ts` 中文词条 | `src/ui/text.ts` 与设置文案 | 统一未验证/认证成功/连接异常、当前状态、暂未同步、目标文件夹、展开/收起、手动同步、查看日志等，不拷入 PRO、额度或 OpenAPI 提示 |
| 新装自动同步默认值 | `src/settings-data.ts` | 默认关闭、30 分钟、启动时同步；已有安装仍保留各自的开关、周期及启动策略 |

有意保留的差异：豆包采用本地网页登录而非 Token 表单，单向下载而非双向同步，处理对话而非多种笔记。界面当前为简体中文，未移植原项目的全部语言词库。平台协议、分页、笔记字段及历史数据不因 UI 复用而改名或迁移。两个仓库仍无共同运行时依赖；本轮不为实现复用而改动原项目。
